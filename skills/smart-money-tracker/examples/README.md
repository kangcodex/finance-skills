# Examples

This directory contains reference outputs from the smart-money-tracker skill.

## `sample-report.md`

A copy of the most recent run's output (`../reports/latest.md`), kept here as a canonical example of the report structure the skill produces. The file shows the section layout (13F, Congress, House Reps, Convergence Signals).

When the upstream data sources (SEC EDGAR, InsiderFinance.io, House Clerk) are reachable and the run is successful, the same structure will contain:

- **13F section** — list of 30 institutional whales + their recent position changes, conviction scores, and net volume
- **Congress section** — list of recent STOCK Act disclosures, sorted by date, with member, ticker, transaction type, amount
- **House Reps section** — list of House Clerk disclosures (skipped if `--13f-only`, `--congress-only`, or `--no-house-reps` was used)
- **Convergence Signals** — tickers where whales and Congress overlap, signaling high-conviction setups

The current `sample-report.md` may appear sparse because it was generated when data sources were unreachable or the run was mode-restricted. For a rich, recent example, run the skill:

```bash
python scripts/smart_money.py
```

…and inspect `../reports/smart-money-YYYY-MM-DD.md` for that day.

## Where the real data lives

- `../reports/` — historical daily outputs (one `smart-money-YYYY-MM-DD.md` per run)
- `../reports/latest.md` — symlink/copy of the most recent run
- `../reports/source-verification-latest.json` — upstream source audit
- `../reports/source-discrepancies-latest.md` — discrepancies between expected and observed upstream content

## How to read a real report

1. **Top section** (`## 13F`) — net position changes, ranked by conviction or volume
2. **Middle section** (`## Congress`) — most recent STOCK Act filings, with member + ticker + amount
3. **Convergence section** — the cross-signal. This is the skill's main value-add: when 5+ whales and ≥1 congressman are positioned the same way on a name, it's flagged here.
4. **Bottom line** — `"Generated by Smart Money Tracker"` stamp at the very end
