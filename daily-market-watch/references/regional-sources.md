# Regional News Source Map

Curated source lists and search queries per region. Use these as the **default** source set for any region-zoom request. Mix official-primary sources (central banks, ministries, statistical offices, exchanges) with reputable secondary news outlets.

Always include the source URL inline in the report's `## Sources` block.

## Citation Hygiene

- Always include the **publication date** when citing a news URL — many sites change headlines over time.
- For live data (yields, FX, index levels), cite the source + the timestamp you read it.
- If a URL 404s or returns a paywall, drop the citation rather than guessing the content.
- For official sources (central bank, ministry, statistics office), prefer the primary URL over third-party coverage.
