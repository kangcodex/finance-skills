# Setting up Polymarket on Amoy

To get started with Polymarket on the Amoy testnet:

1. Create a MetaMask wallet and switch to the Amoy network.
2. Get some test USDC from a faucet (search "Amoy USDC faucet").
3. Go to polymarket.com, connect your wallet, and switch to testnet mode.
4. Place a small test order to confirm the UI works.

That's it — you should be ready to trade on Amoy in a few minutes. Let me know if you need help with anything else.
