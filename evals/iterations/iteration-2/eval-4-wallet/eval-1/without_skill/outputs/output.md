# Upgrading to mainnet

To go from Amoy to Polygon mainnet:

1. Update your MetaMask to point at Polygon mainnet.
2. Get some real USDC (you can buy it on an exchange and send to your wallet).
3. Update the runtime config to use the mainnet RPC endpoint.
4. Place a small test order on mainnet to confirm everything works.

You'll also need to set up session keys — these allow the agent to trade on your behalf without signing every transaction. Most Polymarket users set this up via the Polymarket UI.

For a $50 bankroll, I'd recommend starting with a small position size (1-2% per trade) and scaling up as you get comfortable.
