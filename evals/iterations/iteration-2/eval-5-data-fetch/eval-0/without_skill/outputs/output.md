# Fetching weather forecasts

I can help you get the latest weather forecasts. Here are the main sources I recommend:

- **NOAA** (api.weather.gov) — free, no key needed, good for US locations.
- **Open-Meteo** (open-meteo.com) — free, no key, global coverage.
- **Tomorrow.io** — paid, very accurate, has a free tier.
- **Visual Crossing** — paid, good historical data.

For each market, you would want to:
1. Look up the location.
2. Call the relevant API.
3. Get a probability of precipitation or temperature threshold.

You can store the results in a JSON file. Let me know which markets you're tracking and I'll write the code.
